# ELI5 Azure Networking

- Preset: `paper` (Primer-like warm light)
- Length: about 74 seconds, 4 scenes, 1 chapter
- Audience: beginners meeting Azure networking for the first time
- Through-line: every cloud networking question is really about who gets to
  knock on whose door.

Storyboard:

1. `S01_Title` - title card, through-line spoken over it.
2. `S02_Neighborhood` - a VNet group draws in as "neighborhood" is spoken;
   VM nodes appear as "houses"; subnet groups as "streets"; NSG pills as the
   "fence". Every reveal keyed with `wordFrame`.
3. `S03_Peering` - two VNet groups, a peering arrow with traffic pulse keyed
   to "bridge", and a callout ("Closed by default, opened deliberately")
   keyed to "closed", spaced well clear of the diagram.
4. `S04_Recall` - plain recap: four labeled boxes (VNet, subnet, NSG,
   peering) with their metaphors as sublabels, appearing as each term is
   spoken.

Grounding: VNet, subnet, NSG, and peering semantics per Microsoft Learn Azure
Virtual Network documentation. No text or figures reproduced; concepts
restated in original words and diagrams.
