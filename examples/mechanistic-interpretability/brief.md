# Mechanistic Interpretability

- Preset: `chalkboard` (3Blue1Brown-like dark)
- Length: about 88 seconds, 4 scenes, 1 chapter
- Audience: curious practitioners, no ML prerequisites beyond "a model has
  weights"
- Through-line: a neural network is a machine we have not finished reading
  yet.

Storyboard:

1. `S01_Title` - serif title card.
2. `S02_Circuit` - a neuron node appears at "sum" with the KaTeX equation
   a = sigma(sum w_i x_i + b); input nodes and weight arrows draw in at
   "input"; at "circuits" two more neurons and a dashed circuit boundary
   appear.
3. `S03_CurveDetector` - axes draw immediately (no dead air), then an
   activation curve draws across the plot timed from "Show" to "fires";
   callout "Found, not programmed" keyed to "Nobody".
4. `S04_Recall` - plain recap boxes: neuron, circuit, curve detector, each
   with a one-line definition.

Grounding: neuron/circuit framing and the curve detector example per the
Distill Circuits thread (Olah et al., "Zoom In: An Introduction to
Circuits", distill.pub, CC BY 4.0). The activation plot is an original
illustrative sketch, not reproduced data; no figures copied.
